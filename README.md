# Top-Down RPG ⚔️

A **top-down RPG** developed using **Unity and C#** as a personal learning project.

The goal of this project is to explore and deepen my understanding of game development systems, practice Unity features and improve my C# programming skills by building core RPG mechanics.

## 🎮 Gameplay

Explore a top-down world, interact with enemies, and develop your character through combat and progression systems. The project aims to include inventory management, shops, and other classic RPG mechanics as development progresses.

## 🛠️ Technologies

- **Unity** – Game engine
- **C#** – Programming language

## 📚 Learning Objectives

- Implement player movement and input handling
- Explore physics and collision detection using colliders
- Create enemies and basic enemy behaviors
- Implement HP and damage systems
- Develop attack and combat mechanics
- Build an inventory system
- Create shops and item purchasing mechanics
- Work with camera movement and player tracking
- Implement enemy and object spawning systems
- Develop experience points and level-up mechanics
- Create and manage character animations
- Build user interfaces (UI) for gameplay systems
- Add sound effects and audio feedback
- Implement game saving and loading systems
- Improve code organization, maintainability and C# skills

## 🚀 Getting Started

1. Clone this repository.
2. Open **Unity Hub**.
3. Add the cloned project to Unity Hub.
4. Open the project using its compatible Unity version.
5. Open the main scene and press **Play**.
